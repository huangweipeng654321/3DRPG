# The Little Fox's Wonderful Adventure

## 📖 Background
A Unity 3D action RPG showcasing enemy AI, pathfinding and character animation.

## 🎮 Functionality
Wave-based combat and tactical boss battles, with FSM enemy AI, NavMesh pathfinding and animation logic.

## 🛠️ Tech Stack
Engine: Unity
Language: Unity Visual Scripting + C#

## 🚀 How to Run
1. Clone the repository.
2. Open in Unity.
3. Run the main scene.
